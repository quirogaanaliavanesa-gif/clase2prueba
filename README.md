# Organismo Sonoro (Torpid mink)

Arte generativo audiovisual interactivo creado con **p5.js** y **p5.sound**.

Proyecto importado desde [p5.js Web Editor (Torpid mink)](https://editor.p5js.org/quirogaanaliavanesa/sketches/VTvEMuiw8).

---

## 🌌 Características

- **Pantalla Completa (Fullscreen)**: El canvas se adapta dinámicamente al 100% de la ventana (`windowWidth` y `windowHeight`) sin barras de desplazamiento. Incluye botón interactivo y atajo de teclado.
- **Cámara y Detección de Movimiento**: Analiza en tiempo real el flujo de la cámara web para modular la energía y comportamiento de más de 2000 partículas orgánicas.
- **Sonido Reactivo**: Osciladores sintetizados con filtros pasabajos y reverberación espacial que reaccionan a la cantidad de movimiento captado.
- **Paletas Dinámicas**: Múltiples paletas de color intercambiables.

---

## 🎮 Controles

- **ACTIVAR SONIDO**: Inicia el contexto de audio en el navegador (requiere interacción del usuario por políticas del navegador).
- **CAMBIAR PALETA**: Alterna entre las diferentes armonías cromáticas.
- **MÁS / MENOS REACCIÓN**: Ajusta la sensibilidad de la detección de movimiento.
- **PANTALLA COMPLETA**: Alterna el modo de pantalla completa nativo del navegador (también disponible presionando la tecla **`F`**).
- **REINICIAR**: Limpia las ondas y reinicia las partículas en pantalla.
- **Clic del mouse**: Genera una ráfaga de nuevas partículas y ondas expansivas en la posición del puntero.
